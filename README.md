# Chess-Engine

Basic chess cheat.

# Support server:

[Discord server](https://discord.gg/gMySDxyN5y)

# What does it do?

This is a browser extension for firefox and librewolf and it can autoplay 
your games or show you the best move to play in the game.
This extension also works on both https://chess.com/ & https://lichess.org/

# How this works?

This works via the integrated chess engine inside of the extension that runs locally. 
It can play with a maximum depth of 100 and win almost 100% of the time against any bot or player.
